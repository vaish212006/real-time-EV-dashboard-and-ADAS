# 🚗 Real-Time Electric Vehicle Dashboard and ADAS Warning System

A real-time Electric Vehicle (EV) dashboard and Advanced Driver Assistance System (ADAS) developed to monitor essential vehicle parameters and provide intelligent safety alerts. The project integrates embedded hardware, sensors, and real-time monitoring to improve driver awareness and enhance vehicle safety.

---

## 📚 About

Design and development of a real-time Electric Vehicle (EV) Dashboard and Advanced Driver Assistance System (ADAS), integrating embedded hardware and sensors for continuous vehicle monitoring, intelligent warning generation, and enhanced driver safety through real-time visualization and alerts.

---
